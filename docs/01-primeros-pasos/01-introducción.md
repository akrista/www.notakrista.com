# Introducción

**Fill-a-Kit** es un kit de inicio (starter kit) SaaS diseñado para acelerar el desarrollo de aplicaciones modernas utilizando **[Filament](https://filamentphp.com/)** como el framework principal para aplicaciones web.

## ¿Qué es Fillakit?

Fillakit es un proyecto base que combina las mejores tecnologías del ecosistema [Laravel](https://laravel.com/) para crear aplicaciones robustas y escalables desde el primer día.
